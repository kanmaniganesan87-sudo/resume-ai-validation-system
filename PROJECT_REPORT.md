# Resume AI Validation System

This project helps students check whether their resume matches a job
role.

Completed:
- Student dashboard
- Resume upload interface
- Job description input
- Validation percentage
- Matched skills
- Skill gaps
- Recommendations
- Frontend prototype

Currently Working:
The frontend prototype allows students to upload a resume, enter job
details, and view a sample validation result.

Pending:
Real PDF text extraction, AI API integration, real resume matching,
database, live citations, login, and deployment.

Next Steps:
Connect the frontend with a backend and AI API to calculate the real
resume validation percentage.

Project Status:
Review-1 prototype, approximately 35% completed.
