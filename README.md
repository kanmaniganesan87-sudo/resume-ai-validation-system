# resume-ai-validation-system# Resume AI Validation System

## Project Objective

Resume AI Validation System is a student-focused web application that
helps students check whether their resume matches a particular job role.

The system analyses resume skills, projects, and job requirements to
provide a validation percentage, matched skills, skill gaps, and
improvement recommendations.

## Completed Features

- Student dashboard
- Resume upload interface
- Job description input
- Student question input
- Validation percentage display
- Matched skills section
- Skill-gap section
- Project evidence section
- Improvement recommendations
- Responsive frontend prototype

## Current Working Status

The frontend prototype allows students to upload a resume, enter job
details, and view a sample validation result with matched skills,
skill gaps, and recommendations.

## Pending Work

- Real resume-to-job matching
- Database connection

## Next Steps

The next phase will connect the frontend with a backend and AI API to
